# Firebase User Management

React user management practice project with Firebase configuration.

## Project structure

- `src/components/UserManagement.jsx`
- `src/firebase.js`
- `src/App.jsx`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/firebase-database-project.git
cd firebase-database-project
```

Use a dedicated Firebase test project and configure database security rules.

Install Node.js and npm, then run `npm install` and `npm run dev` in the application directory. Open the terminal URL.
